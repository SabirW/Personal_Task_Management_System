# Personal Task Management System

## Project Description
This is a simple console-based Python application designed for personal task management. 
It allows users to add tasks with priorities, view tasks, mark tasks as completed, and delete tasks. 
The project was developed solo following Agile-inspired principles and demonstrates core programming skills and structured development.

## Features
- Add new tasks with priority (Low, Medium, High)
- View all tasks with their status
- Mark tasks as completed
- Delete tasks
- Simple menu-driven console interface
- Input validation to prevent errors

## How to Run
1. Clone the repository or download the zip file.
2. Navigate to the `code` folder.
3. Open terminal/command prompt in this folder.
4. Run the application with:
```bash
python main.py
